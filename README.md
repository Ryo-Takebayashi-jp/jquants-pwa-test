# v7e-alpha23 — Web Technical Screening PoC

DataLake基盤から分析利用へ移行する最初のPoC。

## 実装
- Catalogから基準日に必要な年別Shardを自動選択
- 直近100取引日を取得
- 75日以上データがある銘柄を対象
- 5/25/75日移動平均
- 5日・20日騰落率
- RSI14
- 当日出来高 / 20日平均出来高
- 仮スコアでTop50表示
- 処理時間、利用Shard、対象銘柄数を表示

## 注意
ランキング式は基盤検証用の仮式。デスクトップ版の正式Screeningロジックとはまだ別。
次段階でデスクトップ版との指標・銘柄集合の突合を行う。
